# Heads-or-Tails
This Python program simulates a simple Heads or Tails coin toss. It uses the random module to generate a random integer (either 1 or 2), which represents the two possible outcomes of a coin flip—Heads or Tails. If the generated number is 2, the program prints "Heads". Otherwise, it prints "Tails".

This generator can be used in games, decision-making scenarios, or just for fun when you need a quick, unbiased result from a coin toss.

Features:

Randomized output ensuring fair results.
Lightweight and easy to run in any Python environment.
